Claude Code plugin

Write it so a greenhorn can follow.

A greenhorn is a newcomer who just got off the boat. greenhorn is a Claude Code plugin. It rewrites technical text for a reader who is new to your system.

InstallGuideGitHub

What it does

  1. Stumble. A read-only agent reads your text as a newcomer would. It lists each word, step or jump it cannot follow. It writes the question it would ask.
  2. Ground. Claude answers each stumble from your code, the linked issue or your docs. If no source backs an answer, the item goes on a list of open questions for you. Claude invents nothing.
  3. Example first. The rewrite opens with one sentence of gist. Then one example with real values. Then the mechanism. Each term gets a short definition at its first use.

Install

/plugin marketplace add gagoar/greenhorn
/plugin install greenhorn@greenhorn

greenhorn needs two other plugins: unmistakable (skill asd-ste100) and iceberg (skill iceberg:edit). Both come from the gago-plugins marketplace:

/plugin marketplace add gagoar/gago-plugins
/plugin install unmistakable@gago-plugins
/plugin install iceberg@gago-plugins

If one is missing, /greenhorn:explain stops and prints the command to install it.

The greenhorn test

The test hands your text to a reader that has no access to your repository and no hint of the topic. The reader lists where it stopped. It also writes one sentence for what it thinks the text says.

If that sentence differs from what you meant, the text fails. The reader understood something other than your point.

Take the before text above. A reader like this would stop at Photon, ETag and rehydration. This list is an illustration of the kind of result you get. It is not a recorded run.

Run only the test with /greenhorn:test. It rewrites nothing.

Honest limits

  • The reader is a model. It is not a human newcomer. It finds likely stumbles. It does not prove that a text is clear. A clean result does not prove it either. The final test is a real person.
  • The numbers, such as 5 terms per text, are untested defaults. No study backs them.
  • The method is a hypothesis. We know of no study that compares definition-first with example-first text. The human eval has no results yet.
  • The checker reads the shape of a text. It cannot tell whether a definition is true.
