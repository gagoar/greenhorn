Evidence

greenhorn is a hypothesis with working code. This page says what is checked and what is not.

What we verified

  • The checker finds what the table in the guide says it finds. Every check has a passing and a failing test file in testdata/rules/. A test fails if one is missing.
  • The checker ran on the before and after pair in the README. The output on the home page is the real output.
  • The scripts use no dependency and make no network call.

What we did not verify

  • That a text made with greenhorn is easier for a human to understand. No human has tested it yet.
  • That the model reader predicts what a human newcomer stumbles on.
  • That example-first beats definition-first. We know of no study that compares them.
  • Any number in the defaults. See below.
  • We have not recorded a reading of the primary paper for each work in the next section. We cite no figure from them.

Supporting reading

This is supporting reading, not proof for this tool. The design leans on these works.

  • Concreteness fading: Fyfe et al. (2014). A concrete example first, then a move toward the abstract idea.
  • Analogies that mislead: Gray and Holyoak (2021). An analogy can teach a wrong model. This is why greenhorn allows an analogy only with a stated limit.
  • The worked-example effect and the expertise reversal effect: the Sweller line of work. A worked example helps a novice. The same help can hurt an expert. This is why greenhorn leaves a text alone when the stumble pass finds nothing.

Prior art

coldread by patrykwiener is related. It makes session context readable to a reader who was outside the session.

greenhorn aims at a different gap: the domain concepts that a newcomer lacks. It differs in these ways:

  • The reader agent has no tools and no repository access. It sees only the text and the profile.
  • Each gap is answered from the code, the issue or the docs, or it goes to a list of open questions.
  • The rewrite puts one real example before the mechanism.
  • A fixed TypeScript checker fails on a circular definition and on a missing example.

We have not compared the two tools on the same documents. We make no claim that one is better.

The human eval

The reader is a model, and a model is not a human newcomer. The human eval is the missing step. It has not been run. The folder holds no results.

The protocol compares three versions of each document: the original, the original after polish only, and the full greenhorn rewrite. Fresh readers see one version each. They explain the text in two sentences. Two scorers who do not know the version score each answer from 0 to 2 against the author's intent.

Read the full protocol. The results will be published even if the result is a tie.
